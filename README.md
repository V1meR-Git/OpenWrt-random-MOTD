# OpenWrt-random-MOTD
Замена шпаргалки apk в терминале на OpenWrt 25

### Установка
```sh
curl -L https://raw.githubusercontent.com/V1meR-Git/OpenWrt-random-MOTD/refs/heads/main/install.sh | sh
```
или
```sh
wget -qO- https://raw.githubusercontent.com/V1meR-Git/OpenWrt-random-MOTD/refs/heads/main/install.sh | sh
```
